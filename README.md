# SRM.LAB — SIH PS 142 Demo

Presentation-ready frontend demo for Deep Learning Based Super Resolution Mapping from medium-resolution satellite imagery.

## Run locally

```bash
npm install
npm run dev
```

The demo uses a Sentinel-2 true-color source tile as the 10 m input and presents a simulated 4× SRM result at 2.5 m for the SIH pitch flow.
